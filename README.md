# tokStudiow

Aplikacja webowa odwzorowująca uczelniany system zarządzania tokiem studiów. Projekt realizowany w ramach pracy inżynierskiej.

## Stack
- Frontend: React, TypeScript, Mantine
- Backend: Java 21, Spring Boot, Gradle
- Baza danych: PostgreSQL

## Struktura
```
apps/
└── api/    backend (Spring Boot)
```
